# 第 12 题：模型并行、数据并行、流水线并行

## 一、先算显存账，再选并行方式

训练需同时考虑权重、梯度、优化器状态、激活和临时缓冲；推理没有反向梯度和训练优化器状态，但 KV cache 在长上下文、大并发时可能很大，不能概括为“少量缓存”。

教学例子：175B 参数，假设低精度权重 2 字节、低精度梯度 2 字节、FP32 主权重 4 字节、Adam 的 m/v 共 8 字节，每参数共 16 字节，合计 **2.8 TB（十进制）**，尚未计激活和临时内存。若梯度采用 FP32，则合计约 3.15 TB。实现不一定采用上述全部副本，必须先说明口径。仅 BF16 权重也约 350 GB。

## 二、DP：同模型，不同数据

普通复制式 DP 在各副本上运行不同数据，训练时同步梯度并保持参数更新一致。它通常提升吞吐，不降低每份副本的模型状态显存；固定全局 batch 增加 DP 时，每副本的 batch 反而减小，通信占比可能增加，不能保证线性加速。

DP 可以与 TP/PP 组合，此时一个“模型副本”跨多张卡，并非每张卡都有完整模型。ZeRO/FSDP 则进一步在数据并行组中分片存储状态：ZeRO-1 分优化器状态，ZeRO-2 再分梯度，ZeRO-3 再分参数。需要时通信获取参数，和把一次矩阵乘拆开计算的 TP 不同。

推理中的数据并行副本通常独立处理不同请求，不需要训练式的梯度同步。

## 三、TP：把一层的张量计算拆开

以两层 FFN 为例，行向量写法 Y=σ(XW1)W2。W1 按输出列分块为 W1_i，各卡计算自己的隐藏通道；W2 按输入行分块为 W2_i，各卡产生局部输出，再归约相加。非线性之前各隐藏块独立，不必先收集完整中间层。

注意力也可以按头等方式分片。TP 的通信通常频繁，适合高带宽互联；具体采用 all-reduce、all-gather 或 reduce-scatter 以及次数，取决于布局、序列并行和实现。**TP≤8 不是算法限制**，8 卡只是某些服务器常见的拓扑配置。

## 四、PP：按层分阶段，用 micro-batch 填流水线

PP 把层分到不同阶段，阶段之间传激活，训练时还反向传激活梯度。多个 micro-batch 错开执行，减少某些阶段空等的气泡。1F1B 指稳态交替安排一次前向和一次反向，不等于所有时间都没有空闲。

在阶段均衡、忽略通信、简单非交错调度的教学模型中，p 个阶段、m 个 micro-batch：

- 气泡时间相对理想有效计算时间约为 (p−1)/m。
- 气泡占总时间的比例约为 (p−1)/(m+p−1)。

例如 p=4、m=8，前者为 37.5%，后者约 27.3%，两种分母不能混用。真实调度还受前反向时间、负载均衡、交错与通信影响。增加 micro-batch **数量**可摊薄气泡，不是无限增大单个 micro-batch；还要权衡显存、kernel 效率与全局 batch。

## 五、3D 并行计算例子

TP=8、PP=4、DP=16，总设备数 8×4×16=512。一个模型副本分布在 8×4=32 张卡上，共有 16 个副本；梯度通常在持有对应参数分片的 DP 组内同步，不是所有卡都交换一份完整模型梯度。

若每个 DP 副本的 micro-batch 为 b，累积 m 次，忽略变长样本等细节，全局 batch=b×m×DP。TP 和 PP 不额外乘进样本数量。

常见布局是把频繁通信放在高速域内，但“TP 机内、PP 跨机”是经验策略，要按互联、层大小和性能测量选择，不能当成硬规则。

## 六、面试答法与自测

单卡放不下先定位是模型状态、激活还是推理 KV 占主导，再考虑低精度、状态分片、激活重计算、TP 和 PP；能放下后扩 DP 提吞吐。这不是唯一固定顺序，应同时评估通信、延迟、batch 和硬件。

DP 分数据，TP 分层内张量计算，PP 分层并流水执行；三者可以组合。ZeRO-3/FSDP 的状态分片不等于 TP。TP/PP 也可能改善速度，DP 的分片变体也可以省显存，不能绝对地把它们分成“只管容量”和“只管速度”。

自测：512 卡组合有 16 个模型副本；p=4,m=8 的教学气泡占总时间约 27.3%；推理无 Adam 状态但 KV 可能成为主要限制。

参考：[Megatron-LM TP](https://arxiv.org/abs/1909.08053)、[3D 并行与流水线](https://arxiv.org/abs/2104.04473)、[ZeRO](https://arxiv.org/abs/1910.02054)。
