对于双变量问题，例如两数之和 $a_i +a_j =t$，可以枚举右边的 $a_j$，转换成单变量问题，也就是在 $a_j$ 左边查找是否有 $a_i=t-a_j$，这可以用哈希表维护。
我把这个技巧叫做枚举右，维护左。

```python
ans=min_s=s=0
```

取整
``` python
import math
#向上取整
print(math.ceil(1.3)) # 输出: 2
print(math.ceil(1.6)) # 输出: 2
print(math.ceil(-1.3)) # 输出: -1
print(math.ceil(-1.6)) # 输出: -1

#向下取整 = 整除//
math.floor(-0.5) # -1
math.floor(1.6) # 1 

#四舍五入
round(1.5) # 2
round(-1.5) # -2
round(-0.5) # 0
round(0.5) # 0
round(2.5) # 2
round(100.5132, 2) # 100.51

#向0取整
int(-0.5) # 0
int(-0.9) # 0
int(0.5) # 0
int(1.9) # 1
```
