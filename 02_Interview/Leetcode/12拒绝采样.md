我们在一个更大的范围内生成随机数，并拒绝掉那些不在题目给定范围内的随机数，此时保留下来的随机数都是在范围内的。

使用均匀分布的一个分布去替代另一个均匀分布
用 Rand7() 实现 Rand10()

``` python
def rand10():
	while True:
		x=rand7()-1
		y=rand7()-1
		a=x*7+y
		if a<40:
			return a%10+1

```
本质上就是取概率相等的 10 个数

在圆内随机生成点

```python
class Solution:

    def __init__(self, radius: float, x_center: float, y_center: float):
        self.xc=x_center
        self.yc=y_center
        self.r=radius

    def randPoint(self) -> List[float]:
        u, theta = random.random(), random.random() * 2 * math.pi
        r = sqrt(u)
        return [self.xc + r * math.cos(theta) * self.r, self.yc + r * math.sin(theta) * self.r]

```

**随机生成一个半径**：为了使点在圆内均匀分布，半径的平方需要在[0, 1]内均匀分布，然后乘以实际半径。这是因为圆的面积与半径的平方成正比。具体来说，我们首先生成一个均匀的随机数`u`在[0, 1]，然后取半径`r = sqrt(u) * radius`。这样能确保点在圆内均匀分布。
