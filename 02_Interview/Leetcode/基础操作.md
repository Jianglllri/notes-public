# 排序

```python
n, k = map(int, input().split())
fans = []

for i in range(1, n + 1):  # 编号从 1 开始
    like, fav = map(int, input().split())
    support = like + fav * 2
    fans.append((support, fav, i))  

# 排序规则：
# -support: 支持力度大的排前面
# -fav: 收藏数大的排前面
# i: 编号小的排前面
fans.sort(key=lambda x: (-x[0], -x[1], x[2]))

# 取前 k 名
ans = [fan[2] for fan in fans[:k]]

# 输出编号（从小到大）
ans.sort()
print(" ".join(map(str, ans)))

```

# 堆

```python
import heapq

n, k = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

notes = [(b[i], a[i]) for i in range(n)]  # (评论数, 点赞数)

# 按评论数从大到小排序
notes.sort(reverse=True)

heap = []   # 小根堆，存点赞数
sum_likes = 0
ans = 0

for b_i, a_i in notes:
    heapq.heappush(heap, a_i)
    sum_likes += a_i

    if len(heap) > k:
        sum_likes -= heapq.heappop(heap)

    if len(heap) == k:
        ans = max(ans, sum_likes * b_i)

print(ans)

```

1. 与运算（AND）：
- 任何数和0做与运算，结果是0，即 x & 0 = 0。例如，5（101） & 0 = 0。
- 任何数和其自身做与运算，结果是自身，即 x & x = x。例如，5（101） & 5（101） = 5（101）。
1. 或运算（OR）：
- 任何数和0做或运算，结果是自身，即 x | 0 = x。例如，5（101） | 0 = 5（101）。
- 任何数和其自身做或运算，结果是自身，即 x | x = x。例如，5（101） | 5（101） = 5（101）。
1. 异或运算（XOR）：
- 任何数和0做异或运算，结果是自身，即 x ^ 0 = x。例如，5（101） ^ 0 = 5（101）。
- 任何数和其自身做异或运算，结果是0，即 x ^ x = 0。例如，5（101） ^ 5（101） = 0。
- 异或运算满足交换律和结合律，即 a ^ b ^ c = a ^ (b ^ c) = (a ^ b) ^ c。例如，5（101） ^ 3（011） ^ 4（100） = 5 ^ (3 ^ 4) = (5 ^ 3) ^ 4。
1. 非运算（NOT）：
- 非运算会反转操作数的所有位。例如，~5（101） = 2（010）。
1. 左移运算（SHL）：
- 左移n位等于乘以2的n次方，即 x << n = x * 2^n。例如，5（101） << 2 = 20（10100）。
- 左移运算不改变操作数的符号位。
1. 逻辑右移运算（SHR）：
- 右移n位等于除以2的n次方，即 x >> n = x / 2^n。例如，20（10100） >> 2 = 5（101）。
- 逻辑右移运算会用0填充移位后产生的空位。
1. 算术右移运算（SAR）：
- 算术右移运算会用符号位填充移位后产生的空位，因此它可以保持负数的符号。例如，对于负数-5（1011） >>> 2 = -2（1110）。
